# 主动话题

本插件由 Sirin 发起并维护，使用 OpenAI Codex 协助开发与迭代。

为 AstrBot 增加按群控制的主动发言能力。插件默认不会在任何群自动发送消息，必须由管理员在目标群执行 `/主动话题 开启`。

插件会复用该会话当前使用的文本模型与人设，并参考开启后的近期群聊内容生成话题。固定触发和随机触发都受允许时段、每日上限、冷却时间和群聊沉默阈值约束。

## BotMesh 兼容

`botmesh_compat_enabled=true`（默认）且 BotMesh 已加载时，主动话题会按当前平台账号和群聊读取该 Bot
的有效 BotMesh 群人格、动态关系和可联系目录，并使用 BotMesh 已整合
`chat_history_context` 的持久化历史。主动生成没有 Agent 工具，因此不得冒充其他 Bot 的意见；只能用
邀请或提问的方式让其他 Bot 参与。

发出的正文会附加不可见的 BotMesh 签名展示帧，避免登记 Bot 把主动话题当成普通 Bot 消息再次唤醒，
同时让 BotMesh 的近期历史收集器识别正文。BotMesh 未安装、未加载、当前账号未纳入关系网或兼容调用
失败时，插件会自动回退到原生 Persona 和自身近期消息，不影响调度与发送。

## 群内命令

```text
/主动话题 开启
/主动话题 关闭
/主动话题 状态
/主动话题 频率 低|中|高
/主动话题 间隔 120 300
/主动话题 上限 3
/主动话题 冷却 90
/主动话题 沉默 30
/主动话题 概率 70
/主动话题 时段 09:00 22:30
/主动话题 固定 09:00,21:30
/主动话题 固定 关闭
/主动话题 测试
/主动话题 重置
```

修改命令只允许 AstrBot 管理员、群主和群管理员使用。由于 QQ 官方事件通常不携带可靠的群角色字段，默认允许 QQ 官方群成员管理本群设置，可通过 `allow_qq_official_members` 关闭。`状态`与`帮助`允许普通群成员查看。

## 频率预设

- 低频：随机间隔 240–480 分钟，每日最多 2 次，冷却 180 分钟，群聊沉默 45 分钟后才触发。
- 中频：随机间隔 120–300 分钟，每日最多 3 次，冷却 90 分钟，群聊沉默 30 分钟后才触发。
- 高频：随机间隔 60–120 分钟，每日最多 5 次，冷却 45 分钟，群聊沉默 15 分钟后才触发。

使用 `间隔`、`上限`、`冷却`、`沉默` 或 `概率` 命令后，该群会显示为“自定义”频率。

## 调度规则

自动消息只有同时满足以下条件才会发送：

1. 插件总开关和本群开关均开启。
2. 当前位于允许发言时段。
3. 当日主动消息数量未达到上限。
4. 距离上次主动消息超过冷却时间。
5. 群聊已连续沉默到设定阈值。
6. 到达固定时间，或到达随机候选时间并通过概率判断。

随机时间在每次成功发送或概率未命中后重新抽取，不会按分钟连续抽签。固定时间和随机时间碰撞时只发送一条。插件将下一次时间、每日计数和近期话题持久化到 `data/plugin_data/astrbot_plugin_proactive_topics/state.json`，重载后不会重复固定消息。

## 注意

- QQ 官方适配器的发送必须复用最近一次 `AstrMessageEvent`。插件会保存每个已开启群的最近事件，并沿用 response2image 的 `event.send` 路径；如果服务重启后还没有收到该群的新消息，则会等待下一条群消息刷新发送事件。
- 插件只记录已开启群聊的少量近期文本，用于让话题衔接自然；可在配置中把 `max_context_messages` 设为 `0` 禁用记录。
- 固定时间也受冷却、沉默、允许时段和每日上限约束。错过配置中的宽限时间后不会补发。
